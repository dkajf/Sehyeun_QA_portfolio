## VSCode와 GitHub 활용

### 목표

- QA 및 코드 리뷰 과정에서 활용되는 Git 워크플로우 이해
- rebase, cherry-pick 등을 활용한 커밋 히스토리 관리 연습
- 특정 브랜치에서 커밋 분리 및 재구성 경험

### 학습 내용
- Git 커밋 히스토리 관리 방법
- 코드 리뷰를 고려한 커밋 단위 구성
- rebase 및 cherry-pick을 활용한 브랜치 관리

### 실행 순서
1. 코드 프로그래밍 문제를 md 파일을 이용해 명세적으로 정리한다
2. 명세에 기반해 코딩을 한 뒤 Git에 커밋 한다
3. 커밋 히스토리를 기반으로 셀프 코드 리뷰를 한다
4. rebase, merge, cherry pick 등을 이용한 커밋 구조를 재구성 해본다
