### TC_ID
TC_Enhancement_001

### Test Scenario
정밀 단조 성공 시 장비 단조 단계 상승 확인

### Precondition
- 단조 해금 퀘스트 완료
- 인벤토리에 단조가 가능한 장비 존재
- 단조에 사용할 같은 부위의 노란색 품질 재료 장비 존재
- 장비가 생산된 지역의 정밀 단조제 존재

### Test Steps
1. 정밀 단조 UI 열기
2. 정밀 단조 할 장비 선택
3. 재료로 사용할 장비 선택
4. 단조 버튼 클릭

### Test Data
- 장비 : 열 작업용 강화 골격(단조 대상)
- 재료 장비 : 열 작업용 강화 골격(재료)
- 추가 재료 : 정밀 단조제 (해당 지역 타컨텐츠 보상)

### Expected Result
- 정밀 단조 성공 시 단조 단계가 1단계 상승한다
- 장비의 확정 단조 누적 카운트가 0으로 초기화 된다

## State Transition Table
<br />

| Current State | Event     | Next State | Description   |
| ------------- | --------- | ---------- | ------------- |
| 단조 가능         | 단조 성공     | 단조 가능      | 장비 단조 단계 상승   |
| 단조 가능         | 단조 실패     | 실패 누적      | 확정 단조 카운트 증가  |
| 실패 누적         | 단조 실패     | 실패 누적      | 누적 카운트 계속 증가  |
| 실패 누적         | 누적 카운트 최대 | 확정 단조 성공   | 단조 단계 상승      |
| 단조 가능         | 최대 단계 도달  | 단조 불가      | 단조 버튼 비활성화    |
| 단조 불가         | 단조 시도     | 단조 불가      | UI에서 단조 불가 유지 |

 - 정밀 단조 시스템은 장비별 단조 단계와 누적 카운트 기반 확정 단조 로직을 포함하고 있어, 상태 전이 기반 테스트 설계로 주요 변화와 예외 상황을 검증하였다
