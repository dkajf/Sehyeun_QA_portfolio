## Bug Report - TC_ID_001 보너스 점수 미적용

### Environment
- Platform : PC (Bluestack 5)
- OS: Windows 11 recent release
- Game version : Google playstore recent release

### Severity
Major

> 플레이어 UX에 혼란을 유발, 불쾌함 조성

### Priority
Medium

> 특정 상황에서 발생

### Reproduction Steps
 1. 미니게임을 시작한다
 2. 정상적으로 8턴 진행한다
 2. 마지막 턴 종료 후 결과 화면으로 이동한다

### Expected Result
- 최종 점수 계산 시 보너스 점수도 정상 합산된다
- 보너스 점수를 적용한 최종 점수 기준으로 승리 UI가 표시된다

### Actual Result
- 최종 점수 비교판에서 보너스 점수가 합산되지 않았다
- 실제 경기 결과가 플레이어의 패배로 표시된다
