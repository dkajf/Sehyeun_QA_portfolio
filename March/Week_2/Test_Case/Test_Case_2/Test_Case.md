## Test scenario - 미니게임 결과 화면 검증
- 트릭컬 미니게임
<br />

---

#### TC_ID
TC_RESURT_001

#### Test Scenario
- 8턴 진행 후 결과 화면에서 승리 UI가 정상적으로 표시되는지 확인한다

#### Precondition
- 미니게임이 정상적으로 8턴까지 진행된 상태
- 점수판 상 유저 본인의 승리가 확정된 상태

#### Test Steps
1. 8턴 마지막 행동을 수행한다
2. 결과 화면 로직이 자동으로 시작되는지 확인한다
3. 로딩 중 점수 비교판이 표시되는지 확인한다
4. 로딩 완료 후 승리 애니메이션 및 승리 UI가 표시되는지 확인한다

#### Expected Result
- 마지막 행동 이후 결과 화면으로 자동 전환된다
- 로딩 중 보너스 점수가 반영된 최종 점수 비교판이 표시된다
- 최종 점수 비교판이 점수 계산 결과와 일치한다
- 로딩 완료 후 승리 애니메이션과 승리 UI를 표시한다

#### Edge Case
- 보너스 점수 반영이 되는지 확인 필요
- 점수판과 최종 승패 결과가 다르게 표시되지 않는지 확인 필요

#### TC_ID
TC_RESURT_003

#### Test Scenario
- 상대 플레이어가 게임 도중 강제 종료했을 때, 되었을 때, 승리 처리와 결과 화면이 정상 표시되는지 확인한다

#### Precondition
- 미니게임이 정상적으로 진행 중인 상태

#### Test Steps
1. 게임 진행 도중 상대 플레이어의 프로그램을 강제 종료한다
2. 상대 플레이어의 연결 끊김을 감지하는지 확인한다
3. 결과 화면 로딩이 자동으로 진행되는지 확인한다
4. 결과 화면에서 승리 UI를 확인한다

#### Expected Result
- 상대 플레이어의 연결 종료가 정상 감지된다
- 결과 화면 로직으로 자동 전환된다
- 플레이어 본인의 보너스 점수는 최종 점수판에 정상 반영한다
- 상대 플레이어의 점수는 룰에 따라 점수판에 0점으로 표시한다
- 로딩 완료 후 패배 애니메이션과 패배 UI를 표시한다

#### Edge Case
- 강제 종료 시 결과 화면으로 전환되지 않고 대기 상태에 빠지지 않는지 확인 필요
- 강제 종료 시점이 게임 시작 직후, 점수 계산 직전 이어도 승리 처리가 정상 작동 하는지 확인 필요
