## VSCode와 GitHub 활용

### 목표
- CLI 기반 Todo Manager 프로젝트를 통해 Git 워크플로우 학습
- QA 및 코드 리뷰 환경에서 사용되는 Git 커밋 관리 방식 이해
- rebase, cherry-pick 등을 활용한 커밋 히스토리 정리 연습
- 브랜치 전략을 활용한 기능 개발 및 히스토리 재구성 경험

### 학습 내용

#### Git Workflow
- feature 브랜치 기반 개발
- 코드 리뷰를 고려한 커밋 단위 구성
- squash / rebase를 활용한 커밋 정리

#### Commit History Management
- interactive rebase
- cherry-pick을 활용한 커밋 이동
- merge vs rebase 비교

#### CLI Program Development
- Python 기반 CLI 프로그램 설계
- 파일 기반 Todo 데이터 관리
- 명령어 파싱 구조 구현
