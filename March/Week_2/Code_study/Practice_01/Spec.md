## Problem Specification
### Problem
#### BOJ 1920

- 문제
N개의 정수 A[1], A[2], …, A[N]이 주어져 있을 때, 이 안에 X라는 정수가 존재하는지 알아내는 프로그램을 작성하시오.

- 입력
1. 첫째 줄: 정수 N (1 ≤ N ≤ 100,000)
2. 둘째 줄: N개의 정수 A
3. 셋째 줄: 정수 M (1 ≤ M ≤ 100,000)
4. 넷째 줄: M개의 정수 X
이때 정수는 -2^31 <= X < 2^31

- 출력
각 X에 대해 A 배열에 존재하면 1, 없을 시 0 출력
각 결과에 한 줄 할당

- 예시
5
4 1 5 2 3
5
1 3 7 9 5

1
1
0
0
1

### Process Flow
1. 정수 N 입력
2. N개의 정수를 벡터 A에 저장
3. 정수 M 입력
4. M개의 정수 X 입력
5. 각 X에 대해 다음을 수행
    A 배열에서 X 탐색
    존재하면 1 출력
    존재하지 않으면 0 출력
    줄내림

### Idea
큰 범위이므로 binary_search 활용이 필요
